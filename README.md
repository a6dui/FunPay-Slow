# 🐌 FunPay Slow — Premium Automation Ecosystem

![Banner](https://github.com/a6dui/FunPay-Slow/raw/main/banner.png)

**FunPay Slow** — это современная, быстрая и безопасная экосистема для автоматизации торговли на FunPay. Управляйте своими аккаунтами, лотами и серверами через единый, интуитивно понятный интерфейс.

---

## ✨ Основные возможности

- 🚀 **Мгновенная работа**: Оптимизированный движок на Python и FastAPI.
- 🛠 **Каталог плагинов**: Десятки готовых решений (AutoRobux, Discord Boost, Steam Guard и др.).
- 🛡 **Безопасность**: Все данные (Golden Key) хранятся локально и шифруются. Мы не имеем доступа к вашим аккаунтам.
- 📊 **Админ-панель**: Полный контроль над статистикой, продажами и балансом.
- 🤖 **Telegram Интеграция**: Управляйте ботом прямо из мессенджера.
- 💻 **Кроссплатформенность**: Доступно для Windows и macOS.

---

## 🛠 Технологический стек

*   **Backend:** Python 3.10+, FastAPI, Aiogram 3.x
*   **Frontend:** HTML5, CSS3 (Vanilla), JavaScript
*   **Database:** PostgreSQL (Cloud) / SQLite (Local)
*   **Deployment:** Render / Vercel

---

## 🚀 Быстрый старт

1. **Скачайте приложение** из раздела [Releases](https://github.com/a6dui/FunPay-Slow/releases).
2. **Получите Golden Key** своего аккаунта FunPay (инструкция внутри приложения).
3. **Наслаждайтесь автоматизацией!**

### Для разработчиков плагинов:
Мы предоставляем удобное SDK для создания собственных модулей на JavaScript. Ознакомьтесь с `sdk.html` в исходниках.
