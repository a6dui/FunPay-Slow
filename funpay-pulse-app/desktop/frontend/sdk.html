Разработчикам Slow SDK

Документация API и инструменты для создания собственных плагинов и интеграций.

POST /api/v1/plugins/register

Регистрация нового плагина в системе Slow. Требуется API-ключ партнера.

curl -X POST https://api.funpayslow.com/v1/plugins/register \ -H "Authorization: Bearer YOUR_TOKEN" \ -d '{ "name": "MyAwesomePlugin", "version": "1.0.0", "description": "Auto-delivery for Roblox" }'

GET /api/v1/accounts/status

Получение текущего статуса всех подключенных аккаунтов воркера.

{ "status": "success", "data": [ { "id": "acc_123", "name": "Seller_1", "online": true }, { "id": "acc_456", "name": "Seller_2", "online": false } ] }
